# Times Table Star: website

Landing page, support, privacy policy and press kit for the Times Table Star
iOS app, published with GitHub Pages so the App Store listing has working URLs.

- index.html: landing page (the root URL)
- support.html: support, contact and FAQ
- privacy.html: privacy policy (linked from the App Store, do not move)
- press.html: press kit page; downloads live in press/
- site.css, fonts/, img/: shared styles, the app's own fonts, optimised art

Plain static HTML and CSS: no build step, no JavaScript, no analytics.

Source of truth for support and privacy lives in the app repository under `support-site/`.
